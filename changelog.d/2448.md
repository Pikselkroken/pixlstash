- The Media sidebar is now a tree. Each project opens in place to show its
  people and sets, with "Not in a project" last, and a Library / Folders switch
  below Review shows the same library the way PixlStash's default folder
  layout files it: each project's people and sets, then Global and
  Unassigned. Right-click a folder to open it in your file manager.
- Find in library, at the top of the sidebar, filters the tree by name. When
  nothing matches it offers to search your pictures instead.
- All media and Favourites always show the whole library; a project's own row
  shows all of that project.
