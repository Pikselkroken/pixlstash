- The Media sidebar has a Library / Folders switch below Review. Library is
  the project picker and the People and Sets it narrows, as before. Folders
  shows the library the way PixlStash's default folder layout files it: each
  project's people and sets, then Global and Unassigned. Right-click a folder
  to open it in your file manager.
- Find in library, at the top of the sidebar, filters people, sets and
  folders by name. When nothing matches it offers to search your pictures
  instead.
- All media and Favourites always show the whole library; pick a project in
  the Library picker to see all of it.
