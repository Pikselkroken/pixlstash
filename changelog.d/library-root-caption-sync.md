- Caption files beside the pictures in your library's own folder can now be
  kept in sync with PixlStash, the way a reference folder's already are: a
  tags file and a description file per picture, read back in when edited on
  disk and written out when edited in PixlStash. Confirming a caption pattern
  on import turns it on; Settings, the open library's menu, "Caption files..."
  turns it on or off and names the files.
