- Character sheets can be drawn with MiniMax H3: from words with an H3
  text-to-image workflow, and from a reference picture with the H3 sheet
  workflow PixlStash now ships. An H3 workflow takes H3 LoRAs only.
- Sheets have a 4K size (5280×3168) for MiniMax H3, which draws best large.
  The size toggle greys out what the chosen model does not draw well: 4K for
  the other models, Small and Medium for H3.
