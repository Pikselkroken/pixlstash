- Copy and paste tags. In the picture view, click tag chips to select them and
  choose Copy (Ctrl+C), then press Ctrl+V on another picture, on a selection
  in the grid or in the tag dialog (T) to add them. Each paste is one undo
  step. The copy also goes to the system clipboard as text for a prompt.
- The tag dialog's add field turns comma-separated text, such as a pasted
  prompt, into one tag per item.
- The search suggests tags as you type. Enter finds pictures with the tag,
  Shift+Enter without it, Ctrl+Enter searches the words, and a pasted prompt
  becomes one filter per tag.
- Tag chips come in three sizes, under User settings.
- Star ratings only react to a digit pressed on its own, so Ctrl+2 no longer
  sets two stars.
