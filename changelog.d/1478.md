- Edit a workflow's LoRAs from the Workflows inspector: delete a LoRA, change
  the order they apply in, or add one from your model shelf. Saving writes a
  new workflow, so the original and the pictures made with it stay as they
  are.
- Skip a LoRA for one run in the Run popup, including one this ComfyUI does
  not have. Nothing about the workflow changes.
- Save as recipe lists each LoRA on its own row, lets you take any of them off,
  and marks a LoRA your model shelf cannot identify instead of leaving it out.
