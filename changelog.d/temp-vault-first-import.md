- A folder you point PixlStash at stays yours until you say what to do with it.
  Aborting the first import, closing the question, or losing power part way
  through now leaves the folder exactly as it was: no library database, no
  thumbnail cache, and every picture where you had it. PixlStash asks about the
  folder again next time instead of opening a half-imported library.
- "Start an empty library here" is offered whatever a folder holds, so a folder
  of pictures you would rather not index has an answer other than closing.
