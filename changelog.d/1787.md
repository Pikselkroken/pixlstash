- An API token can now work in every library. Until now a token stopped
  working the moment you switched library, which meant an AI agent or a script
  had to be given a new one each time. With more than one library, the token
  list has an **Every library** switch per token, and **Connect AI agent** has
  **Use in every library**: the token then acts on whichever library is open.
  Only the owner, signed in from the local network, can change it, and share
  links always stay with the library they were made in.
- Fixed: the API token list failed to load once a share link to a set, a
  character or a project existed.
