- PixlStash now uses the graphics hardware on Apple Silicon Macs. Tagging,
  image search and face matching ran on the processor before, however fast the
  Mac was, because PixlStash only ever looked for an NVIDIA card. The built-in
  tagger is roughly twenty times faster on the GPU.
- The memory budget on the Settings screen now means something on a Mac. It
  starts at half the machine's RAM, up to 8 GB, and the screen shows how much
  PixlStash is actually using — device memory there is the same memory
  everything else on the Mac is sharing, so PixlStash keeps within a share of
  it rather than claiming the lot, and a batch that would not fit falls back to
  the processor instead of failing.
- PixlStash no longer reports a missing NVIDIA utility on a Mac that was never
  going to have one.
- JoyCaption is still offered on a Mac and now says what it will cost before
  you pick it: around 8 GB just for the model, out of the same memory
  everything else is using.
