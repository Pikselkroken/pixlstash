- `plugins install --with-deps` now installs each dependency from the exact
  artefact it resolved, instead of looking the package name up again. A
  dependency a plugin pinned to a URL, to a VCS commit, or to its own
  `--find-links` directory used to be re-fetched by name, so what landed could
  be a different project that happened to share it. The listing also says where
  each dependency actually came from when that is not the usual package index,
  so you can see what you are agreeing to.
