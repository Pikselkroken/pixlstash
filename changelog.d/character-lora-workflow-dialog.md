- Right-click a person or a picture set and choose **Create with LoRA…** to
  make new pictures with the LoRA attached to them. The Run dialog opens with
  the workflows for that LoRA's base model listed first, the LoRA already
  added, and the new pictures filed back to that person or set.
- **Add LoRA** in the Run dialog now works on any workflow: when there is no
  free LoRA loader, the LoRA is added in a loader of its own for that run,
  and the workflow's own LoRAs keep running.
