- Sets can now sit inside a person or another set: a LoRA dataset is a set
  under the person or set it is of. The sidebar shows People and Sets as trees
  you can open and close, the Set picker lists the current person's sets first
  with **New set in <Person>…**, and a set's menu gains **New set inside…** and
  **Move out of…**. Training a set under a person makes a character LoRA of
  them; a set under a set starts as a concept.
