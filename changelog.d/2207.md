- A folder inside a model folder can now be removed from the Folders tree in
  the Models sidebar: *Remove folder…* in its menu, or Del on the row. An empty
  folder goes at once; otherwise a dialog lists every file going to the Trash,
  the files the shelf does not list included, and every person, picture set and
  workflow that loses a model. Shift deletes permanently instead. When
  something breaks, or the delete is permanent, the folder's name must be typed
  first.
