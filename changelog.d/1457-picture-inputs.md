- The Run popup fills a workflow's picture inputs. Each one is a row in a new
  Pictures section: your selection where the workflow reads it, a picture you
  choose from your library, or one you keep with the pin so every later run of
  that workflow uses it. Run a one-picture workflow over five selected
  pictures and you get five runs, one per picture, with nothing to set up.
- A workflow with a reference picture you have pinned and one more picture
  input runs on your selection straight away: the selection goes into the
  input that is left. With two or more open inputs you say which one takes the
  selection, and the workflow remembers it.
- A workflow whose single picture input you run over a selection now reads
  those pictures. Before, the popup started from their recipe and ignored the
  pictures themselves.
- *Use as input for…* is back in the lightbox and on the Recipe tab: it runs
  another workflow on that picture.
- "Stack new pictures with the ones they came from" is back as a checkbox in
  the Run popup. It is ticked when your pictures are fed into the workflow and
  not remembered between runs. Each new picture joins the stack of the picture
  it was made from.
- If a picture you pinned has been deleted, its slot is empty and says so;
  choose another to run.
- Remix's template and recipe modes are not part of this. There has never been
  an "upscale a selection" run, and there still is not.
