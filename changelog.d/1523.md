- A workflow set you made yourself now offers to merge with the matching set
  from your pictures. When pictures used the set's checkpoint with models the
  set lacks, the card says so ("1204 pictures need 3 more · Merge…") and the
  open set shows those models, dashed, in the slots they would go in. Merge adds
  them all, Add takes one, and Keep separate is remembered until you choose
  Offer the merge again from the set's menu. All of it can be undone.
