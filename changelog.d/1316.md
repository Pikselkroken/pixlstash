- `pixlstash-mcp` is a read-only MCP server: an AI agent can search your
  library and read pictures, tags and recipes through an API token. Give it a
  read-only token and it sees only what that token is allowed to see.
- **API Tokens → Connect AI agent** in account settings mints that token and
  hands back the finished client configuration to paste, so connecting an agent
  no longer means copying a secret into a JSON file by hand.
