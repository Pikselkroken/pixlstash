- Workflows you save in ComfyUI now arrive in PixlStash automatically: while a
  ComfyUI address is set, PixlStash checks ComfyUI's saved workflows every
  minute, and once when you link ComfyUI. It is on by default; turn it off in
  Settings › ComfyUI with "Pull workflows from ComfyUI".
- Saving a pulled workflow again in ComfyUI no longer makes a second card: the
  change becomes a new version of the same workflow, which keeps its pictures,
  recipes, defaults and pins. The first version and the newest 49 are kept.
  Run and Open check ComfyUI for a newer save first, and use the stored
  version if ComfyUI does not answer. Workflows you imported or copied yourself are never changed
  by a ComfyUI file.
- A workflow deleted from ComfyUI keeps its card and its versions here.
