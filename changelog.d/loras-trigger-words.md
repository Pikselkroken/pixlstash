- LoRAs on the model shelf now show their trigger word, the word you type in a
  prompt to call the LoRA up. Importing a training run from ai-toolkit takes it
  from the run's own settings.
- You can set or change it yourself: select one or more LoRAs and choose **Set
  trigger words…**. Leave the field empty for a LoRA that needs none.
- Until you set one, a LoRA that is assigned to a person shows that person's
  name as its trigger word.
