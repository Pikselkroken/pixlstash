- Outpainting: a workflow card's menu gains **Convert to Outpainting
  workflow**, which stores an `(outpaint)` copy of an image-to-image, image
  edit or text-to-image workflow. In the lightbox Edit tab, the new **Extend**
  tool (X) lets you drag the picture's edges outwards, or type each side, with
  a Feather slider for the blend. The run redraws only the new area, and the
  recipe records the padding.
- **Convert to Inpainting workflow** now accepts text-to-image workflows too.
