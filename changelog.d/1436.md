- `pixlstash-mcp --allow-write` lets an AI agent edit workflows: it can hand a
  workflow's graph out as a file, store an edited graph back as a new workflow
  card, and preflight or run it so the pictures land in your library. With
  ComfyUI's own MCP server connected too, the agent can check its edits
  against your ComfyUI before storing them.
- **API Tokens → Connect AI agent** has a **Read and write workflows** choice
  that mints the full-access token this needs and adds the flag to the
  configuration it hands back.
