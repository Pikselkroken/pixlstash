- Settings no longer has a Workflows section. The ComfyUI host and port are
  set on their own Settings › ComfyUI tab, in the desktop app and in a
  browser alike. Add a
  workflow by dropping it on the Workflows view, and delete one from its panel
  on the right of that view.
- A workflow file dropped under a name you already use is kept alongside the
  old one rather than offering to replace it. To replace one, delete it first.
