- Tags are now organised into groups. Every library starts with defaults
  (Anomaly, People, Hair, Face & expression, Body, Clothing, Accessories,
  Pose & action, Setting, Objects, Animals, Composition, Style & meta) that
  file thousands of common tagger tags for you. A picture's tags gain a
  By group tab with headings you can fold, copy and drag tags between, and
  right-click → Move to group files any tag. Moving a tag refiles it on
  every picture, and Undo takes it back.
- Tags that name a colour ("blue eyes", "blonde hair") show their chip in
  that colour, still faded by how sure the tagger was.
- The Tags view (formerly Tags to review) opens on Groups, for filing many
  tags at once, and can import a Danbooru tag database (.xlsx or .csv) to
  file tags by its categories. Filters → Tags can require or exclude a whole
  group ("any Character tag").
- Open reviews are managed from the sidebar: right-click a review to abort
  or archive it. The board no longer repeats the list at the bottom.
