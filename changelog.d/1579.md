- The MCP server's `get_recipe` now says whether a workflow's model forks into
  several sampler passes and which LoRAs feed each pass. It also counts the
  nodes of each class and gives the path that opens the picture's workflow card
  in PixlStash. `list_pictures` and `count_pictures` can filter by that card's
  `workflow_key`.
- A replaced or revoked API token now makes the MCP server say that the token
  was rejected and that the MCP client must reconnect, instead of a bare
  `401: Not authenticated`.
