- The Models workspace has its own sidebar. Its header picks a model folder to
  limit the list to, with that folder's size and how full its drive is. Below
  it are Sets, All models, Favourites, Recently added and In no set yet, rows
  for each type and base model, Training runs, and an Add models button.
- The model list shows Name, Type, Base, Size, Added and Sets, banded by type,
  and the Models rail now describes what is selected: a set's models, the
  workflows it ran in, its latest pictures and when it was last used, or a
  model's file, sets and pictures. With nothing selected the rail shows the
  shelf's totals, disk use by type and the largest files.
- Group by folder is gone; pick a folder in the sidebar instead.
