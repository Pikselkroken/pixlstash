- Outpainting: a workflow card's menu gains **Convert to Outpainting
  workflow**, which stores an `(outpaint)` workflow that runs FLUX.1 Fill
  with the card's prompt. In the lightbox Edit tab, the new **Extend** tool
  (X) lets you drag the picture's edges outwards, up to three times its size
  on each side, or type each side, with a Feather slider for the blend. Only
  the new area is drawn and the original's pixels are kept. Without the Fill
  model the run says so and offers the download.
