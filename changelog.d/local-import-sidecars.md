- Importing a folder of pictures that already sit inside the library (the
  first-run offer and "Add a library" on a folder holding pictures) now reads
  the caption files beside them. A `photo.txt`, `photo_tags.txt` or
  `photo.caption` next to `photo.jpg` becomes that picture's tags or
  description, and the tagger only runs on pictures that have none. Reference
  folders already did this; the in-place import skipped the files and tagged
  everything from scratch.
