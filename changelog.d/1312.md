- Pictures made with A1111, Forge and other web UI forks are grouped into
  workflows like ComfyUI pictures, and count towards the models they used on
  the model shelf. PNG, JPEG and WebP are all read. Pictures already in your
  library are read once after the update.
- A LoRA used by such a picture is counted as "a file of that name" rather than
  as a confirmed match: the web UI records a LoRA by a hash of part of the file,
  which cannot be checked against the shelf.
