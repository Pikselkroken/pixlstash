- A training run named after a device name Windows reserves (`con`, `nul`,
  `aux`, `com1`, `lpt1` and the like, also as `con.v2`) no longer fails to
  start on Windows. Its folder is named by the run's id instead.
- Training on from an earlier step keeps the abandoned steps' loss curve in the
  `take-<n>` folder with the rest of what is set aside, and the run no longer
  shows the abandoned last step until the trainer logs again.
- Moving the model store or the face models into or around a folder that is
  already on the model shelf is refused, as registering such a folder by hand
  already was.
