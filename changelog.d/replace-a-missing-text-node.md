- A text node from a custom pack your ComfyUI does not have (WAS's **Text
  Multiline**, Comfyroll's **CR Text**) no longer stops a run. PixlStash writes
  its text straight into whatever it fed and runs without the pack, and a
  prompt typed into the Run popup now reaches such a node. The Run popup says
  so before you press Run. A WAS text holding a `[token]` still asks for the
  pack.
