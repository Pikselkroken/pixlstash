- *Create a training set…* now makes the set at once, under the person, and
  builds it on the set's own screen instead of in a dialog. Leave it any time:
  the sheets keep drawing, and the set's row (or *Open set* on its Character
  sheet run in Tasks) brings the build back exactly as you left it. While it
  is being built the row says where it stands: drawing, drawn, picking.
  *Cancel set* deletes it and stops its sheet runs.
- Fixed: closing the training set dialog lost the character sheets being
  drawn, with no way back to them.
- The sheet form is more compact: the sheet workflow is chosen in the toolbar,
  and only workflows that can actually draw a sheet are offered. Body is no
  longer a separate field: describe the build in the description, and the
  sheets no longer add "average build" against it. *Draw a* follows the
  description.
