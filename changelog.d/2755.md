- Changed: NVIDIA GPU acceleration moves to CUDA 13, so the desktop app and
  the Docker GPU image run the same PyTorch release as everywhere else instead
  of an older one. It needs NVIDIA driver 580 or newer; with an older driver
  the desktop app no longer offers the GPU download, and the Docker GPU image
  will not start. An existing CUDA 12.8 download keeps working until you
  install the CUDA 13 one from Settings › Compute, which then removes it.
