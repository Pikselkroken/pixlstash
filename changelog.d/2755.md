- Changed: NVIDIA GPU acceleration moves to CUDA 13.2, so the desktop app and
  the Docker GPU image run the same PyTorch release as everywhere else instead
  of an older one. The desktop app needs NVIDIA driver 580 or newer and no
  longer offers the GPU download on an older one; the Docker GPU image needs
  driver 595 or newer and will not start on an older one. An existing CUDA
  12.8 download keeps working until you install the CUDA 13 one from
  Settings › Compute, which then removes it.
