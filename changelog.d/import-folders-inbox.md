- An Inbox under Review in the sidebar holds what you added lately that has
  no person and no set yet, from import folders or anywhere else. It covers the
  last 2 weeks by default; the Added menu in its toolbar picks another period
  and shows how many pictures each would hold. Putting a picture in a set or
  giving it a person takes it out of the Inbox; it stays in your library.
- Import folders moved out of the sidebar into Settings › Import folders, and
  the sidebar's Folders section now holds reference folders only. The Filter
  menu gains Imported from, to see everything one import folder brought in.
