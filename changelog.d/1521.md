- Workflows built with the ComfyUI-PixlStash nodes can now be run from
  PixlStash. Each node is judged on its own: the model loaders, searches and
  likeness gates just run; a project, set or character loader runs when this
  library has what it names; the picture loader is handed the picture you
  chose; and the picture saver runs as an ordinary save, so each picture is
  imported once. When a node cannot run, the Run popup names it and says why.
