One rule from here on, running both ways
If you re-organise in PixlStash

A file moves only when its folder stops being true. Adding a second project or a second person moves nothing, because the folder it is in is still correct. Removing the one its folder is named after moves it, because otherwise that folder would be lying. Counted first, one undo.

If you move pictures in your file manager

The same rule backwards: PixlStash changes an assignment only when the move makes it untrue. Drag a picture into another project's folder and it belongs to that project now. Drag it somewhere the layout does not describe and nothing changes but the path. New files are imported.

Which means importing your library moves nothing at all. The folders are where the assignments came from, so every one of them is already true.
