PixlStash first run

Where should your pictures live?

A library is a folder on your disk. PixlStash keeps its index inside that folder, so the whole thing is one thing you can copy, back up or move.

Before this, unchanged: the telemetry question that already ships

TelemetryConsentDialog already asks this once, on first startup, and records that it asked however you leave it. It is not redrawn here and it does not need to be. It is on this artboard only so the order is written down: the question comes first, then the folder.

What may PixlStash send?

PixlStash can check pixlstash.dev once a day for a new version. Several past releases fixed critical security bugs, so I’d suggest leaving this on. You could also help PixlStash improve by sending a random number alongside it.

No check

Nothing leaves your machine. You’ll need to watch for security releases yourself.

Check for updates

Sends your version and platform. Nothing else.

Check + random ID

Adds a random number, so I can tell ten people using PixlStash once from one person using it ten times.

Never sent: your images · your tags, captions or filenames · your prompts

If you asked for an empty library and the folder is not empty
You said start a new library, but there are 28,412 pictures in ~/Pictures/Generations.
Bring them in and PixlStash reads your folder names as the organisation, without moving anything. Or point it somewhere else.
There is no third answer, and “start empty in here anyway” is not one. A library that ignores the 28,412 pictures sitting in its own folder is a trap: the next scan finds them, new pictures get filed in among them, and two ideas of one folder is one too many. Which button was pressed a screen earlier does not get to cause that.
