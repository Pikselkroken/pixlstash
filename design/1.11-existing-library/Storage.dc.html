A segment can hold more than one thing, and the first that applies wins. A segment with nothing to fill it is skipped rather than left as an empty folder, which is what keeps the tree two deep instead of five. A new, empty library starts on exactly this layout, since it has no folders to read a better guess from.
A picture only moves when its folder stops being true

Not whenever something about it changes. Only when the folder it is sitting in would otherwise be saying something that is no longer the case.

A folder that does not match the layout is never wrong

Drag something into _unsorted or a folder of your own and there is nothing for PixlStash to contradict, so it stays there. Permanently. That is the override, and it needs no setting.

This is also why the rule is safe to leave on. The worst it can do is move a picture out of a folder that has stopped describing it.
