You are running a development build

This machine declares PIXLSTASH_INSTALL_TYPE=dev, so it is reported as our own signal and subtracted from the published usage numbers. Update it from source rather than from a release artifact.

Update from source

git pull
pip install -e .
cd frontend && npm install && npm run build

Restart python -m pixlstash.app to load the new code. If you meant to follow the packaged instructions instead, unset PIXLSTASH_INSTALL_TYPE and reload.
