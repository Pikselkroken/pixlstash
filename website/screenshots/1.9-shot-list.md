# PixlStash 1.9 website media

Capture with the dark theme, the left sidebar open, a realistic library, and no
private filenames, paths, tokens, URLs, or install ID visible. Use a 16:10 or
16:9 desktop window at 1600 px or wider. Export stills as high-quality JPEG and
screen recordings as muted H.264 MP4. Keep the pointer away from important UI
at the end of each recording.

## Required

1. `ScreenshotDuplicates.jpg` — **duplicate-review feature still**
   - Open the Duplicates destination with at least three useful candidate groups.
   - Keep one row focused and show its complete candidate strip, confidence and
     reason labels, the sidebar Duplicates count, and the queue toolbar.
   - Avoid an open menu or dialog; the screen should explain the feature at a
     glance.
   - Used by: What's New and Features.
   - Alt text: "PixlStash Duplicates view with likely copies grouped for review."

2. `10-DuplicateReview.mp4` — **duplicate-review walkthrough, 15–20 seconds**
   - Start in the grid and open Duplicates from the sidebar.
   - Open Compare for one group, inspect the candidates, close Compare, choose a
     cover or exclude one mismatch, then Stack the group.
   - Finish by using Undo so the group returns to the queue. This is important:
     the video should prove that undo and redo reaches a complex workflow, not
     just simple metadata edits.
   - Record at a deliberate pace; no voiceover is needed.
   - Used by: What's New.

3. `ScreenshotUndoHistory.jpg` — **hero still, highest priority**
   - In the normal grid, make three visibly different changes first (for example
     rating, tag, and move or assignment).
   - Open the toolbar history so its named steps are visible; keep both Undo and
     Redo controls in frame.
   - Used by: home-page 1.9 teaser, What's New hero, and Features.
   - Alt text: "PixlStash undo history showing several recent library changes."

4. **Keep cover only pair** — show both discovery and the safety preview.
   - `ScreenshotKeepCoverOnly.jpg`: a selected stack with its context menu open
     and Keep cover only visible as the action.
     - Alt text: "PixlStash picture menu with Keep cover only available for a selected stack."
   - `ScreenshotKeepCoverOnly2.jpg`: the confirmation explaining how many
     pictures move to the Scrapheap, that the files remain on disk, and that the
     whole operation is reversible in one Undo step.
     - Alt text: "Keep cover only preview showing three pictures moving to the recoverable Scrapheap in one undoable step."
   - Used together by: What's New.

5. `ScreenshotMultiProject.jpg` — **multi-project organisation still**
   - Show one character or picture set assigned to at least two clearly named,
     non-sensitive projects. Prefer the assignment menu plus enough sidebar
     context to make the shared membership obvious.
   - Used by: What's New and Features.
   - Alt text: "One PixlStash character assigned to more than one project."

6. `11-SuggestMorePictures.mp4` — **person-assignment walkthrough, 12–18 seconds**
   - Open a person's context menu and choose Suggest more pictures.
   - Let the ranked results appear, adjust the likeness threshold once, select a
     convincing subset, and use the counted assignment action.
   - End on the success receipt and the updated result state.
   - Used by: What's New and Features.

7. `ScreenshotPrivacy.jpg` — **privacy settings still**
   - Open Settings → Privacy with both Check for updates and Send an anonymous
     install ID switched off.
   - Frame the explanatory copy and the "Never sent" note, but crop or obscure
     the actual install ID.
   - Used by: What's New.
   - Alt text: "PixlStash Privacy settings with optional update checks and anonymous install telemetry turned off."

## Optional

8. `ScreenshotMixedStacks.jpg` — open Mixed stacks with one flagged stack
   selected and its members visible together. Frame the cohesion or mismatch
   information, the comparison controls, and the Split and Keep actions so the
   reason for reviewing the stack is clear without opening another dialog.
   - Alt text: "PixlStash Mixed stacks view showing a stack flagged for review."

9. `ScreenshotStackFilter.jpg` — the grid filter panel with Stacked selected and
   stack badges visible in the resulting grid.

## Integration order

The HTML deliberately ships the 1.9 copy without broken placeholders. Once the
assets exist, add `ScreenshotUndoHistory.jpg` to the home teaser and What's New
hero first. Use the duplicate-review video early on the What's New page because
its final Undo action demonstrates that the new history reaches a complete,
multi-step workflow. Add the remaining media to the matching release and feature
cards, then run `node website/screenshots/extract-script.mjs` so `script.json`
stays in sync.
